## Context

> **TL;DR:** Databricks has two halves, and where each runs is the whole design question.

| Half | Runs in | Holds |
|---|---|---|
| **Control plane** | Databricks' AWS account | UI, API, job scheduler, cluster manager |
| **Compute plane** (classic) | **Our** AWS account, our VPC | Clusters that read and write our data |

Clusters must call home to the control plane. **SCC** (secure cluster connectivity)
means the cluster opens the connection outward through a relay; nothing connects in,
and clusters need no public IPs. The question is only *which road* that outbound call takes.

## What we decided

> **TL;DR:** each choice below closed a door the previous one left open.

| Question | Choice | Why |
|---|---|---|
| Sign up where? | AWS Marketplace | Databricks charges land on the AWS bill, inside our budget alerts (D-014b) |
| Which AWS plan? | Paid | The Free plan blocks Marketplace and deletes everything when credits end (D-018) |
| Serverless or classic? | Classic in our VPC | Serverless shows none of the network controls this project exists to evidence (D-015b) |
| Which cloud? | AWS | Azure trial forces a NAT; GCP classic runs on deprecated GKE (D-020) |
| Road home: NAT or PrivateLink? | PrivateLink | NAT still has a route to the internet. PrivateLink has none (D-019, D-021) |
| Which tier? | Enterprise | PrivateLink requires it (D-021) |

## Tricky parts

> **TL;DR:** trial credits never pay for cloud infrastructure, and first cost estimates lie.

### 1. The trial credit trap (Azure, 2026-09-21)
- **Symptom:** an Azure workspace started billing with no cluster running.
- **Cause:** the Azure trial forces a hybrid workspace, which creates a NAT gateway billed hourly.
- **Fix:** deleted the same day.
- **Lesson:** a Databricks credit pays Databricks (DBUs), never the VPC, NAT or endpoints it creates. Same on all clouds.

### 2. "Why sign up on AWS if Databricks is SaaS?"
- The Marketplace only changes **billing and account linking**. The workspace still
  lives in Databricks' account; our VPC still hosts compute. Benefit: one bill, one budget.

### 3. The cost estimate was wrong twice
- First draft forgot the PrivateLink endpoints; the second priced interface endpoints per
  endpoint instead of **per endpoint per AZ**. Correct: ~USD 64/month vs ~38 for NAT.
- **Lesson:** price every hourly resource × AZ × hours before choosing.

### 4. Is NAT insecure?
- Not really: traffic is still TLS and SCC. But a NAT is a road to the whole internet
  that a compromised library could use. PrivateLink makes "no public egress" literally true,
  which matters for finance data before results are published.

### 5. Which account is the CLI pointed at?
- Trying Azure revealed the Azure CLI was logged into an **employer** tenant by default;
  gcloud also holds employer service accounts. Cleared Azure before any write.
- **Lesson:** check the active cloud account before every CLI command (risk R-05).
