## Context

> **TL;DR:** Unity Catalog (UC) is Databricks' single place for grants, lineage and audit.

Without UC, each cluster decides access by itself. With UC, every read goes through one
permission system, and every table knows where its data came from ([LLD 3](../architecture/lld-data-platform.md)).

## What we built

> **TL;DR:** UC assumes our role, the role can only touch `dbx-uc`.

| Piece | Role |
|---|---|
| `dbx-root` | Workspace system files (notebooks, logs) |
| `dbx-uc` | All governed finance data. No bucket grant to Databricks: reached only via the role |
| UC role | Read/write `dbx-uc` only; trusts the UC master role with an external ID |
| Storage credential + external location | UC's pointer to the role and the bucket, **isolated** to this workspace |

## Tricky parts

> **TL;DR:** naming, ordering and trust loops.

### 1. Bucket name too long (2026-09-17)
- **Cause:** 65 characters; S3 allows 63. Found before creation.
- **Fix:** short suffixes `dbx-root`, `dbx-uc`.

### 2. Built the buckets, stopped at IAM
- The Databricks IAM needs the Databricks account ID, which did not exist yet. We did not
  ship IAM that could be neither applied nor tested; it waited for [2.1](2.1-where-databricks-runs.md).

### 3. The external ID comes from UC
- **Cause:** the trust must include an external ID that UC issues *when the credential is created*.
- **Fix:** the order Databricks documents, which is not the obvious one:
  1. create the credential first, naming a role that **does not exist yet**. Its ARN is built
     from parts (account + name), because referencing the role resource would be circular;
  2. create the role with a trust requiring the issued external ID (the confused-deputy defence);
  3. wait for IAM (`time_sleep`), then create the external location. Databricks validates it by
     assuming the role, so a successful apply is itself the proof.

### 4. The role must be self-assuming
- UC requires the role to be able to assume itself. It looks odd; it is documented, and it
  is still scoped to the one bucket.

## Proof

- 2026-09-25 UC validation of the external location: READ, LIST, WRITE, DELETE: PASS.
