## Context

> **TL;DR:** "trust me" is not evidence; a failed check and a lineage graph are.

## Acceptance criteria

> **TL;DR:** critical checks block, warnings record, lineage proves.

- [ ] Critical checks fail the job: keys not null, amounts in range, every sale's store and
      product exist, journals balance.
- [ ] Warning checks write to `ops.dq_results` without failing (e.g. unusual volume).
- [ ] A test run with a deliberately broken file fails the job with a readable message.
- [ ] Unity Catalog lineage shows the path from one Gold table back to the Bronze
      `_source_file`; captured as evidence.
- [ ] Control matrix rows for data quality and lineage move from Planned to Implemented, evidence "tested".

## Out of scope

- Model monitoring and drift (Epic 6).

## Review

> **TL;DR:** before closing, a separate pass tries to prove the work wrong. Checklist: [stories README](README.md#review-checklist).

- [ ] Every acceptance criterion proven with evidence (numbers, logs, test names), not assumed
- [ ] Negative tests: tried to break it (bad input, wrong identity, rerun)
- [ ] Security: no secrets, least privilege, no new egress, grants to groups
- [ ] Cost: new resources priced, nothing left running
- [ ] Data: nothing dropped silently, counts reconcile, rerun gives the same result
- [ ] Failure: what happens if it stops halfway, and is a rerun safe
- [ ] Docs: story, cmdb, STATUS and diagrams updated; each fact in one place
- [ ] Simplicity: anything that could be removed
