## Context

> **TL;DR:** a stored AWS key in GitHub is the most common cloud breach path.

**OIDC** in one line: at each run GitHub signs a short token saying "I am repo X, branch Y".
AWS checks the signature and the claims, then hands out credentials that expire in about an hour.
Nothing long-lived exists to steal.

## What we built

> **TL;DR:** two roles, two trust rules, one manual gate.

| Role | Who can assume it | Can do |
|---|---|---|
| `github-plan` | Any run on `main` | Read everything, lock state, plan |
| `github-deploy` | Only runs in the `aws-bootstrap` environment | Apply, with scoped permissions ([1.3](1.3-least-privilege-deploy-role.md)) |

The deploy workflow is dispatched by hand, you type `apply`, and it applies the **exact
saved plan** it just showed. Releases are cut by semantic-release from Conventional Commits.

## Tricky parts

> **TL;DR:** fixing the first bug revealed a second one it was hiding.

### 1. The hardened OIDC subject
- **Symptom:** the first role assumption was refused.
- **Cause:** GitHub now sends `repo:kheuchi@47268855/retail-finance-platform-infra@1371524439:ref:refs/heads/main`,
  with **numeric IDs**, not the name-only form in most tutorials.
- **Fix:** read the real `sub` claim from the failed run's log, confirmed the IDs via the
  GitHub API, and pinned the trust to them.
- **Lesson:** numeric IDs are safer: renaming or recreating a repo cannot inherit the trust.

### 2. The empty budget email
- **Symptom:** once OIDC worked, validation failed on the budget email.
- **Cause:** the GitHub secret was set with a trailing newline or blank value and arrived as an empty string.
- **Fix:** re-set it with `printf` (no newline) and rewrote the validation message to say what is wrong.

### 3. Checkov that never ran
- **Symptom:** the "advisory" scan passed every time.
- **Cause:** a setup defect meant it did not execute at all; non-blocking hid that.
- **Fix:** repaired. It then found 5 real findings (37 checks). Later it became a required check ([1.5](1.5-security-review-going-public.md)).
