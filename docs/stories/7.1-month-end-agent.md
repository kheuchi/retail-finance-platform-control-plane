## Context

> **TL;DR:** the ML finds; the agent explains and drafts; a person decides.

The controller spends days writing variance commentary for the CFO pack, retyping numbers from
reports ([business case](../conception/business-case.md#todays-close-as-is)). Gold, the reconciliation
and the models already hold every fact needed; what is missing is the first draft.

## Design

> **TL;DR:** infra adds a private road to Bedrock and a credential; the data repo adds one job.

| Piece | Repo | What |
|---|---|---|
| Bedrock runtime endpoint | infra | Interface endpoint in the endpoint subnets, private DNS, 443 from the workspace SG |
| Agent identity | infra | Service principal `finance-month-end-agent`: SELECT on five named Gold tables, MODIFY on `ops.agent_drafts` and `ops.agent_runs` only; `ops.agent_approvals` writable only by a new `finance-controllers` group |
| IAM role + UC service credential | infra | `bedrock:InvokeModel` on the EU profile ARN (eu-central-1) and the foundation-model ARNs in EU regions; trusted by Unity Catalog with an external ID; the agent identity granted ACCESS. Anthropic first-use step done once by the admin |
| Job `month_end_agent` | data | Runs as the agent identity after certified Gold; Converse tool-use loop; max 8 tool calls, output-token cap, timeout |
| Tools (read-only, fixed SQL) | data | `revenue_vs_budget(month)`, `store_margin_alerts(month)`, `reconciliation_exceptions(month)` (no journal text), `forecast(month)`, `cashier_alert_count(month)` (a count only); each tool computes its own variances and percentages |
| Output | data | `ops.agent_drafts`: run, month, draft, citations (tool, row key, value), check result, status `pending_review`, model, tokens |
| Check | data | Every number in the draft must match a cited tool result; unmatched numbers fail the draft (status `rejected_by_check`) |

## Acceptance criteria

- [ ] No public route added: the agent reaches Bedrock only through the new endpoint (flow logs show 443 to the endpoint, no REJECT to the internet).
- [ ] The Bedrock role can invoke only the chosen EU Claude profile; any other model is refused (IAM policy simulator).
- [ ] The agent identity reaches AWS only through the UC service credential; no instance profile, no key.
- [ ] The agent refuses to run unless the latest Gold build is certified.
- [ ] The agent's own identity can read only the five named Gold tables and write only its two ops tables: refusals shown for Silver, `gold.fraud_scores`, a Gold write and a GRANT.
- [ ] No employee-level data reaches the model: tools never return cashier IDs (test).
- [ ] The August 2026 draft (last complete month) covers: revenue vs budget, the four unsupported journals, the store margin alert (S031), the number of cashier cases referred to internal audit, the forecast; every figure cited.
- [ ] The figure check passes on the draft; tests show a wrong or uncited figure is rejected, and journal text cannot reach the prompt.
- [ ] Only the controllers group can write an approval; the agent identity is refused.
- [ ] Prompt, tool calls, draft, token counts and model ID are stored per run.
- [ ] Cost per run recorded (tokens × price).

## Out of scope

- Sending to Teams, ServiceNow or the CFO pack (iPaaS, not built); the approval screen (status column only).
