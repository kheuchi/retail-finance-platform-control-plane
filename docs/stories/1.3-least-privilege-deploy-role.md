## Context

> **TL;DR:** "admin for CI" is the easy way. It also means one stolen token owns the account.

Least privilege means listing exactly which actions on which resources the role needs.
It is the right thing, and it is where most of our failures came from.

## What we built

> **TL;DR:** every statement names its resources; `*` only where AWS allows nothing else.

- Statements scoped to named buckets, roles (`retail-finance-platform-github-*`, `-dbx-*`), the trail, the budget.
- EC2 creates allowed only if the request carries tag `Application=retail-finance-platform`;
  modify/delete only on resources with that tag.
- Break-glass: the human admin user with MFA, documented in a runbook, alarmed ([1.4](1.4-audit-and-alarms.md)).

## Tricky parts

> **TL;DR:** four traps, all at runtime, none visible in code review.

### 1. Terraform reads before it writes
- **Symptom:** the first real deploy failed during *plan*.
- **Cause:** the role could modify the bucket and budget but not read all their settings,
  and Terraform refreshes (reads) everything before planning.
- **Fix:** add the read actions. Recovery needed the human admin: the role could not grant itself the fix.

### 2. Some actions have no resource type
- **Symptom:** the trail applied, then the read-back failed.
- **Cause:** `DescribeTrails`, log deliveries, `ec2:Describe*`, the password policy
  cannot be scoped to an ARN. Scoping them makes them fail.
- **Fix:** a separate statement with `*` for exactly those actions, each documented as a Checkov exception.

### 3. The chicken-and-egg: the two-phase apply
- **Cause:** one apply that both *grants* a permission and *uses* it races IAM propagation.
- **Fix:** apply 1 changes the role only; apply 2 creates the resources. Used for every
  increment since, with no more break-glass.

### 4. Find gaps before the apply (2026-09-24)
- **Fix:** run the **IAM policy simulator** on the planned actions first, including cases
  that must be *denied* (foreign SG, non-project role). It caught 3 real gaps before the
  network apply: SG-rule ARNs, `logs:CreateLogDelivery`, `DescribeVpcEndpointServices` (+ Route 53 for private DNS).

## Proof

- 2026-09-16: two break-glass recoveries, both recorded. 2026-09-17: alerting applied in one clean pipeline run.
- Checkov: 90 passed, 0 failed, 6 justified skips after triage; one over-broad wildcard removed.
