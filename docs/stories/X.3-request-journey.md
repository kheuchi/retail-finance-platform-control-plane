## Context

> **TL;DR:** a newcomer should be able to follow a request without learning cloud topology first.

The owner requested a site and documentation redesign after reviewing the live site. Secret stores,
network boundaries and deployment identities belong in supporting detail. The margin recovery example
remains a separate use case; it must not stand in for the enterprise version of month-end close.

## Acceptance criteria

> **TL;DR:** continuity, truthfulness, readable direction and working links.

- [x] Built and target use the same eight stages and month-end question.
- [x] Simple and Expert keep the same order, labels and positions; Expert expands detail.
- [x] Main workflow reads top to bottom; component calls inside a stage read in order.
- [x] Data preparation is explicitly before the request; finance tables are not rebuilt by the agent.
- [x] Supporting controls are outside the main path, available on demand.
- [x] Proposed production changes and simulated integrations are labelled; no runtime code or cloud changes.
- [x] Architecture, landscape, home and search use the same request model; existing architecture links resolve.
- [x] Markdown architecture screenshots and target overview reflect the new explanation.
- [x] Site checks/build and desktop/mobile browser verification pass; separate review recorded.

## Scope

> **TL;DR:** change the explanation and website only.

Site source, architecture documentation, screenshots, status and inventory. No infra or data-product
repository edits, finance-platform deployments, cloud job runs or resource changes. The owner authorised committing and publishing the static site after reviewing the local redesign. As-built means the demonstrated
implementation; it does not mean the paused platform is currently available to run.

## Review

> **TL;DR:** a separate review pass in the same session checked the final diff and story checklist; it was not an independent reviewer.

| Finding | Resolution |
|---|---|
| Original enterprise target changed the use case | Main target now extends month-end; earlier margin recovery is retained separately |
| Diagrams implied live BI/CFO integrations and a hard budget cap | Intended/simulated channels labelled; budget described as alerts only |
| Supporting services dominated the chart | Credentials, hosting, monitoring and cost moved outside the eight-stage path |
| Replacing screenshots could imply full LLD detail was still drawn | Docs explicitly call them stage-context maps; technical tables remain the detailed reference |
| Old links could lose readers | Legacy section/LLD hashes reveal their stage or supporting context; switching versions preserves the selected stage |
| Browser follow assertion originally expected an exact top offset | Adjusted the browser check to verify visibility; the page can reach its scroll limit near the end |
| Publication evidence | Commit `068fca2`, successful Pages workflow and live browser verification recorded below |

The old business-workflow draw.io and PNG were removed together after the site screenshot replaced them. Network and observability topology diagrams remain frozen because this redesign does not replace their detailed content.
