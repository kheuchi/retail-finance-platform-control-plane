## Context

> **TL;DR:** enterprises start with guardrails, not workloads (D-002).

The first CLI login was the **root user**: the one identity that can do anything,
including closing the account. The project stopped all AWS calls until routine work
moved to a named IAM user, `cheikh-platform-admin`, with temporary browser-issued
credentials (D-007).

## What we built

> **TL;DR:** the minimum every later stack depends on. Code: `bootstrap/` in the infra repo.

| Piece | What it does | Why it matters |
|---|---|---|
| S3 state bucket | Stores Terraform's record of what exists, versioned, encrypted, locked | Without it, two runs can corrupt each other and nothing is recoverable |
| AWS Budget USD 50 | Emails at 50% and 80% actual, 100% forecast | We see spend before it hurts |
| Password policy | 14 chars, complexity, 90-day age | Baseline hygiene auditors check first |

The state started local, then was **migrated** into S3, first in Paris, then in Frankfurt.

## Tricky parts

> **TL;DR:** three traps: a cost trap, a region trap, a tooling trap.

### 1. Control Tower would have burned the credits
- **Symptom:** the enterprise design is a multi-account landing zone (AWS Organizations + Control Tower).
- **Cause:** creating an Organization instantly ends the Free plan credits (USD 100).
- **Fix:** single account now, multi-account kept as a documented reference design (D-009).
- **Lesson:** read the billing terms before the architecture diagram.

### 2. The region changed twice
- **Symptom:** Paris (eu-west-3) supports Databricks, but not custom model and agent serving.
- **Fix:** moved to Frankfurt (eu-central-1). A brief split (state in Paris, workloads in
  Frankfurt) was reverted as needless complexity (D-010 → D-012 → D-013).
- **Lesson:** check the *last* stage's needs (ML serving, agents) before picking a region.

### 3. Terraform could not use the new `aws login`
- **Cause:** Terraform 1.14's S3 backend does not read the new `login_session` credentials.
- **Fix:** export them first: `aws configure export-credentials --format env`.
