# Control Matrix

**Which security controls exist, and how we know.** The full list of 86 controls,
with where each lives and its evidence, is in [cmdb.yml](../../cmdb.yml) → `controls`.

## Summary (2026-09-25)

| Status | Count |
|---|---|
| Implemented | 59 |
| Partial | 4 |
| Planned | 13 |
| Not implemented, on purpose | 9 |
| Accepted risk | 1 |

GuardDuty and Security Hub moved from "unavailable" to "not implemented" when the
account left the Free plan: they now work, but cost money.

Evidence grades: **tested** (we made it fire), **verified** (read back from AWS),
**declared** (in code, applied, not independently checked).

## Strongest controls

- No stored AWS keys anywhere; CI uses OIDC pinned to repo IDs.
- Private network: no internet gateway, no NAT, PrivateLink only. Verified in AWS.
- CloudTrail + alarms on break-glass and root use. Tested.
- Branch protection on `main`, including admins. Tested.
- IAM policy simulator before permission changes. Found 3 gaps before they broke an apply.

## Biggest gaps

- GitHub 2FA off (accepted).
- No alarm on audit-trail or IAM tampering.
- Unity Catalog: storage connected, but no catalogs, schemas or grants yet.
- Checkov cannot see policies generated by the Databricks provider.
